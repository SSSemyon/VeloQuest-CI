## Closed in 0.8.3

- Account-switch and ABA races are blocked with account + epoch operation tokens across restore, ride sync, bike save, catalog selection, quests, privacy, inbox and inventory mutations.
- Cloud bike save is authoritative; a local cache failure is diagnostic and no longer reports that the cloud change was not applied.
- Manual GPX/FIT imports are historical-only and cannot earn rewards based on self-supplied timestamps.
- Route generation has an authenticated durable per-user quota.
- Catalog search indexes the full Garage component surface and brake filtering reads both normalized and human-readable brake fields.
- Compatibility supports compatible, conditional and incompatible evidence outcomes; the seed graph contains all three.
- All 663 enabled catalog rows have category, HTTPS manufacturer evidence, evidence date and explicit model-year evidence. Official-host validation covers all 43 represented brands.
- A deterministic enrichment queue is generated at `catalog-harvester/enrichment-queue.json`.
- CI performs two local Supabase resets to test repeatable migration replay.
