# Hagen catalogue evidence — 0.8.7

The release contains 55 Hagen model-year identities for 2024–2026 across all six official families: MTB, Women, Gravel, Hybrid, Teen Pro and Teen.

Primary evidence is stored in `catalog-harvester/hagen-official-evidence.json` and points to official `hagen.bike` family or product pages. The user-owned Hagen 3.12 is represented for 2025 and 2026. The 2025 identity uses the retained official Series 3 page plus a corroborating dealer URL because a discoverable model-specific 2025 manufacturer page is no longer available.

No compatibility, exact fitment or recommendation was inferred from model naming. Unknown compatibility remains default-deny. Only explicitly evidenced fields are populated.
