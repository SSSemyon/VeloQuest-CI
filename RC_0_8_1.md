# VeloQuest Mobile Alpha 0.8.1 RC

Release-candidate date: 2026-08-11.

## Added after Wave 16

- `regional_adventure` Route Engine mode for 25–50 km loops.
- Separate 25–35 km and 35–50 km distance gates.
- Three intentionally different regional alternatives: `Легче`, `Интереснее`, `Приключение`.
- Regional provider controls: 12 candidates, lower concurrency and longer per-route timeout for public BRouter stability.
- Persistent Light/Dark runtime theme with a Profile switch.
- iPad support (`TARGETED_DEVICE_FAMILY = 1,2`) and Android tablet portrait compatibility.
- Repeatable cross-wave catalogue integrity command: `npm run check:catalog`.
- Dependency security triage and a patched nested `uuid` override.

## Accepted closed-alpha risk

`npm audit` reports 35 high package-level findings, all cascading from the two `image-size` denial-of-service advisories through Metro. The parser is used only by the local build pipeline for repository-controlled assets; it is not shipped as an app input parser. There is no compatible upstream Metro fix at this checkpoint. Full reachability and controls are documented in `SECURITY_TRIAGE.md`.

## External/device gates still open

- Physical Android phone/tablet E2E and current-source APK.

The codebase is software-complete for the agreed 0.8.x scope. Device QA may discover P0/P1 fixes, but new product modules should remain frozen until closed-alpha evidence.
